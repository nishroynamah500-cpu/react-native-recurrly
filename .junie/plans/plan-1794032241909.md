# Requirements

### Overview
Create a "New Subscription" modal form that lets users add subscriptions from the home screen. The modal slides up from the bottom, collects name, price, frequency, and category, validates the input, and adds the new subscription to the home screen's list immediately.

### User Story
As a user, I want to tap the "+" icon on the home screen and fill in a short form so I can quickly add a new subscription without leaving the app.

### Functional Requirements
- **Modal**: Bottom-sheet modal with transparent overlay, slides up animation.
- **Header**: "New Subscription" title + close button.
- **Form Fields**:
  - Name: text input.
  - Price: decimal-pad text input.
  - Frequency: toggle between Monthly and Yearly.
  - Category: chip selection from 8 options (Entertainment, AI Tools, Developer Tools, Design, Productivity, Cloud, Music, Other).
- **Validation**: Name must not be empty; price must be a positive number.
- **Submit**: Creates a subscription object and adds it to the beginning of the home screen's subscriptions list.
- **Reset**: Form resets and modal closes after successful creation.
- **KeyboardAvoidingView**: Applied on iOS.

### Subscription Object Shape
- `id`: unique string (UUID)
- `name`: from form
- `price`: from form (parsed as float)
- `frequency`: Monthly or Yearly
- `category`: selected chip
- `status`: "active"
- `startDate`: today (via dayjs)
- `renewalDate`: startDate + 1 month (Monthly) or + 1 year (Yearly)
- `icon`: `icons.wallet`
- `billing`: same as frequency
- `color`: mapped from category

### Out of Scope
- Persisting subscriptions to a database or storage.
- Editing or deleting subscriptions.
- Internationalization.

# Technical Design

### Current Implementation
- **Home screen** (`app/(tabs)/index.tsx`): Renders a `FlatList` with `HOME_SUBSCRIPTIONS` (imported from `constants/data.ts`) as static data. The "+" icon (`icons.add`) is a plain `Image` with no interaction.
- **Design system** (`global.css`): Already defines all needed classes:
  - Modal: `modal-overlay`, `modal-container`, `modal-header`, `modal-title`, `modal-close`, `modal-close-text`, `modal-body`
  - Auth form: `auth-input`, `auth-label`, `auth-button`, `auth-button-disabled`, `auth-error`
  - Picker: `picker-row`, `picker-option`, `picker-option-active`, `picker-option-text`, `picker-option-text-active`
  - Category: `category-scroll`, `category-chip`, `category-chip-active`, `category-chip-text`, `category-chip-text-active`
- **Components** (`components/`): `SubscriptionCard.tsx`, `UpcomingSubscriptionCard.tsx`, `listHeading.tsx` — all use NativeWind styled classes, `clsx` for conditional classes, and import `@/global.css`.
- **Types** (`type.d.ts`): `Subscription` interface already defined with all needed fields.
- **Dependencies**: `clsx` and `dayjs` already installed. No new packages needed.
- **No existing Modal usage** in the codebase — this will be the first.

### Key Decisions
- **Modal placement**: `components/CreateSubscriptionModal.tsx` — keeps it co-located with other UI components, outside the `app/` routing directory per project convention.
- **State management**: Home screen owns `subscriptions` state (initialized from `HOME_SUBSCRIPTIONS`). The modal is a controlled component via `visible`, `onClose`, and `onSubmit` props.
- **Category color mapping**: Hard-coded object mapping each category name to a hex color (e.g., Entertainment → `#f5c542`, AI Tools → `#b8d4e3`, etc.), consistent with existing subscription colors in `constants/data.ts`.
- **ID generation**: `crypto.randomUUID()` for unique subscription IDs.
- **Date calculations**: `dayjs().add(1, 'month')` for Monthly, `dayjs().add(1, 'year')` for Yearly.

### Proposed Changes

#### New File: `components/CreateSubscriptionModal.tsx`
- Props: `{ visible: boolean; onClose: () => void; onSubmit: (subscription: Subscription) => void }`
- State: `name`, `price` (string), `frequency` ("Monthly" | "Yearly"), `category` (string | null), `errors` (Record<string, string>)
- Renders a `<Modal transparent animationType="slide">` with:
  - Pressable overlay (`modal-overlay`) that closes on press
  - Container (`modal-container`) with:
    - Header (`modal-header`): title + close button
    - Body (`modal-body`): wrapped in `KeyboardAvoidingView` + `ScrollView`
      - Name field (label + `TextInput` with `auth-input`)
      - Price field (label + `TextInput` with `auth-input`, `keyboardType="decimal-pad"`)
      - Frequency row (`picker-row` with two `picker-option` buttons)
      - Category chips (`category-scroll` with `category-chip` buttons)
      - Submit button (`auth-button`)
- Validation on submit: name trimmed non-empty, price parsed as positive float
- On success: builds `Subscription` object, calls `onSubmit`, resets form, closes modal

#### Modified File: `app/(tabs)/index.tsx`
- Add `useState` for `subscriptions` (initialized with `HOME_SUBSCRIPTIONS`) and `modalVisible`
- Wrap `icons.add` image in `<Pressable onPress={() => setModalVisible(true)}>`
- Replace `data={HOME_SUBSCRIPTIONS}` with `data={subscriptions}` in the FlatList
- Add `<CreateSubscriptionModal>` component with `visible`, `onClose`, and `onSubmit` handlers
- `onSubmit` handler: `setSubscriptions([newSub, ...subscriptions])`

### Risks
- **Modal on web**: `animationType="slide"` is ignored on web; the modal still works but without animation. Acceptable for a mobile-first app.
- **KeyboardAvoidingView**: Behavior differs between iOS (`padding`) and Android (`height`). Tested with standard patterns.
- **NativeWind v5 RC**: Class-based styling via `className` is the project standard; no `styled()` wrapper needed for the modal component since all classes are already defined in `global.css`.

# Delivery Steps

### * Step 1: Create CreateSubscriptionModal component
Create `components/CreateSubscriptionModal.tsx` — a bottom-sheet modal with form fields for creating a new subscription.

- React Native `<Modal>` with `transparent={true}`, `animationType="slide"`, and a `visible` prop controlled by the parent.
- Header: "New Subscription" title (`modal-title` class) and a close button (`modal-close` / `modal-close-text` classes) that calls `onClose`.
- Body wrapped in `KeyboardAvoidingView` (iOS `padding`, Android `height`) and `ScrollView`.
- Four form fields:
  1. **Name** — `TextInput` with `auth-input` class, label with `auth-label`.
  2. **Price** — `TextInput` with `auth-input` class, `keyboardType="decimal-pad"`.
  3. **Frequency** — Two toggle buttons (Monthly / Yearly) using `picker-row`, `picker-option` / `picker-option-active`, and `picker-option-text` / `picker-option-text-active` classes. `clsx` for conditional toggling.
  4. **Category** — Horizontal `ScrollView` with chip buttons for Entertainment, AI Tools, Developer Tools, Design, Productivity, Cloud, Music, Other. Uses `category-scroll`, `category-chip` / `category-chip-active`, and `category-chip-text` / `category-chip-text-active` classes.
- Submit button using `auth-button` / `auth-button-disabled` classes. Validates: name not empty, price is a positive number. Shows error text with `auth-error` class.
- On submit: builds a `Subscription` object with `id` (UUID via `crypto.randomUUID()`), `name`, `price`, `frequency`, `category`, `status: "active"`, `startDate` (today via `dayjs`), `renewalDate` (calculated: +1 month for Monthly, +1 year for Yearly), `icon: icons.wallet`, `billing` (same as frequency), and a color mapped from category.
- Calls `onSubmit(subscription)` and resets form + closes modal.
- Uses existing design system classes only: `modal-overlay`, `modal-container`, `modal-header`, `modal-title`, `modal-close`, `modal-close-text`, `modal-body`, `auth-input`, `auth-label`, `auth-button`, `auth-button-disabled`, `auth-error`, `picker-row`, `picker-option`, `picker-option-active`, `picker-option-text`, `picker-option-text-active`, `category-scroll`, `category-chip`, `category-chip-active`, `category-chip-text`, `category-chip-text-active`.
- Imports: `Modal`, `View`, `Text`, `TextInput`, `Pressable`, `KeyboardAvoidingView`, `ScrollView`, `Platform` from react-native; `useState` from react; `clsx`; `dayjs`; `@/constants/icons`.

###   Step 2: Hook modal into home screen
Wire the `CreateSubscriptionModal` into the home screen (`app/(tabs)/index.tsx`).

- Import `CreateSubscriptionModal`, `useState`, and `Pressable`.
- Add `subscriptions` state initialized with `HOME_SUBSCRIPTIONS` (from `@/constants/data`).
- Add `modalVisible` state (default `false`).
- Wrap the `+` icon (`icons.add`) in a `Pressable` that sets `modalVisible(true)`.
